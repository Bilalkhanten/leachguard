# Public datasets (not redistributed here)

Download the official files and save them with these names:

| Dataset | Official source | Save as |
|---|---|---|
| NSL-KDD | https://www.unb.ca/cic/datasets/nsl.html (KDDTrain+.txt, KDDTest+.txt) | `data/KDDTrain.txt`, `data/KDDTest.txt` |
| UNSW-NB15 | https://research.unsw.edu.au/projects/unsw-nb15-dataset (partitioned training and testing sets, CSV) | `data/unsw_train.csv`, `data/unsw_test.csv` |

LEACH-Sim needs no download: `sim.py` generates it, and `leach_sim.csv.gz` in the package root is the exact file used in the paper.
WSN-DS was not available for this study and is not used.
